# 小红书文案写作规范

## 核心原则：换立场，不是压缩长文

长文是**"我帮你看懂"**——读者是学生，你是讲解者。
小红书是**"我看完发现了什么"**——读者是同伴，你是先看过的人。

这个转换决定了所有写法：

| 长文里 | 小红书里 |
|---|---|
| 这条片子讲了… | 我花 13 分钟看完，最颠覆我的是… |
| 作者指出… | 他说了一句话我直接愣住 |
| 这里有问题 | 我当时就觉得不对，查了才知道… |
| 综上所述 | 所以我现在是这样想的 |

**常见错误**：把长文的 `lead` + 几个 `flags` 拼起来，加个标题就发。
读者一眼能看出是"总结"，不是"感受"。

## 结构（300-600 字）

```
第一行：钩子（必须让人停下来）
　　　　
第二行：我的身份/处境（建立可信度）
　　　　
中间：3-4 个具体发现，每个 1-2 句
　　　　
结尾：一句我自己的判断
　　　　
标签：5-8 个
```

### 钩子的四种写法

1. **反常识**：`这个 12 分钟的视频，把我信了三年的一个说法推翻了。`
2. **具体数字**：`15.68%。这个数字比任何"经济周期"的科普都更有用。`
3. **代入痛点**：`每次刷到"康波周期"我都划走，因为我根本不知道他在说什么。`
4. **结果前置**：`我把一条 13 分钟的视频拆成了 14 段，现在终于能跟人聊这个话题了。`

**不要用**：`今天给大家分享一个视频` / `最近看到一个很不错的视频`
——这两种开头等于告诉读者"这条不用看"。

### 中间的"具体发现"

必须**具体到你自己的反应**，不能只陈述结论。

❌ 太干：`康波周期分为四个阶段：复苏、繁荣、衰退、萧条。`
✅ 有反应：`我一直以为"周期"是像四季一样自然轮转的。但他讲到名字叫法各家都不一样，
        起点能差 15 年——那这不就等于说，谁也说不准现在是哪一段？`

### 结尾的判断

要给**明确的个人立场**，但留有余地。不要中立到没有信息。

❌ `总之，这个视频有优点也有缺点，大家可以辩证看待。`
✅ `我的结论是：他的框架值得学，但他的时间表别信。有方向感是好事，有时间表就是幻觉。`

## 标签策略

5-8 个，分三层：

1. **领域词**（2-3 个）：`#经济周期` `#康波周期` `#宏观经济学`
2. **行为词**（2-3 个）：`#视频笔记` `#知识整理` `#自我提升`
3. **长尾/情绪词**（1-2 个）：`#看完终于懂了` `#普通人怎么理解经济`

不要堆 15 个标签，会显得像营销号。

## 排版

- **不用 markdown 语法**（小红书不渲染 `**bold**`）
- 用 **emoji 分段**（每 2-3 段一个），但不要每句都加
- 段落之间空一行
- 单段不超过 3 行（手机屏幕）
- 需要强调时用 `「」` 或单独成行

## 内容红线

1. **不编造视频里没有的话**。要引用就引真实原话。
2. **不假装是自己原创的观点**。如果框架来自视频，说"他提出"。
3. **财经/医疗/法律类内容必须带免责**：`仅个人理解，不构成建议。`
4. **政治敏感内容不要放大**。如果视频里有政治表态，长文可以标注，
   小红书文案里**不引用、不评价、不放大**——只谈知识框架。

## 完整示例

```
我花了 13 分钟看完这条讲"康波周期"的视频，最大的收获不是学会了这个理论，
而是知道了它为什么不能被当成预测工具。

先说背景：我完全不懂经济学。之前刷到"人生发财靠康波"直接划走，
因为满屏都是我认识但连起来看不懂的词。

这次我一句一句拆完了，有三个发现：

① 他的框架其实是对的
价格长期波动 = 货币 vs 产能 的拉锯。钱多货少就涨，货多钱少就跌。
这个不需要什么周期理论也成立。

② 但"周期"是他硬加进去的
五轮周期的起止年份，各家说法差 15 年。一个周期才 50-60 年——
起点能随便挪，那"现在处在哪一段"就等于随便说。

③ 最扎心的是他自己那句
讲完十分钟"现在是萧条期，很危险"，最后说：
「定投的该怎么做就怎么怎么做，现在爱怎么波动就怎么波动，根本无所谓。」

……那前面十分钟是在讲什么？

我的结论：他的分析框架值得学，他的时间表别信。
有方向感是好事，有时间表就是幻觉。

仅个人理解，不构成任何建议。
```

标签：`#康波周期` `#经济周期` `#宏观经济学` `#视频笔记` `#知识整理` `#看完终于懂了`
