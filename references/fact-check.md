# 事实核查方法

不核查的"解读"只是把原话换个说法。这一节解决**怎么查、查什么、查不到怎么办**。

## 判断视频类型（决定核查重点）

先花一分钟判断这条片子属于哪类，核查策略完全不同：

| 类型 | 特征 | 核查重点 |
|---|---|---|
| **事实类** | 科普、教程、纪录片、新闻解读 | 数字、年份、人名、因果关系 |
| **观点类** | 财经分析、时事评论、个人经验 | 论据是否成立、是否可证伪、立场与分析是否混淆 |
| **创作类** | 娱乐、vlog、访谈 | 无需核查，重点在理解内容和语境 |

**最常见的问题**：观点类视频伪装成事实类。
表现为大量使用"数据""规律""必然""历史证明"，但实际推论链条靠类比和选择性举例。

## 必查的三类

### 1. 数字与年份

**任何具体数字都要查。** 这是最容易出错也最容易验证的部分。

搜索式：
- `<数字> <主体>` 例：`美国10年期国债收益率 1981年 峰值`
- 优先看：官方统计（BLS、Fed、世界银行）、学术论文、主流财经媒体

**特别注意**：
- 语音识别常把"三分之二"听成"2%"，"三分之一"听成"1%"。数字异常小（<5%）时要警觉。
- 中文视频里的年份常有一两年的口误。

### 2. 理论地位

用户最需要知道的往往不是"这个理论说什么"，而是**"这个东西靠谱吗"**。

搜索式：
- `<理论名> 争议` / `<理论名> 批评`
- `<理论名> 主流经济学` / `<理论名> 是否被接受`
- 英文：`<theory> criticism` / `<theory> mainstream economics`

**关键判据**：
- 是否有诺贝尔奖级别的认可？没有 ≠ 错，但说明不是共识。
- 是否被归入"异端/非主流"（heterodox）？
- 样本量够不够做统计检验？（长周期理论最大的软肋就是只有 4-5 个样本）

### 3. 可证伪性

问一个问题：**这个说法有没有可能被证明是错的？**

如果没有，那就不是知识，是信仰。

典型不可证伪的表述：
- "十大现象"式清单 —— 任何时期都能凑出十条
- "长期来看" —— 长期是多长？没人能反驳
- "符合吧，完全符合" —— 先有结论再找证据

## 常见逻辑问题清单

写解读时对照这份清单，能抓到大部分问题：

| 问题 | 表现 | 怎么点出来 |
|---|---|---|
| **幸存者偏差** | 用少数成功者证明某个条件有利 | "忽略了分母：同条件下有多少人没成功？" |
| **确认偏误** | 只找支持结论的证据 | "反过来问：如果是繁荣期，能不能也凑出十条？" |
| **不可证伪** | 结论无法被推翻 | "一个能解释任何情况的理论，等于没解释" |
| **自相矛盾** | 前后两个说法不能同时成立 | 明确指出 A 和 B 冲突 |
| **偷换层次** | 把事后解释当成事前预测 | "能描述 1990 年代，不等于能预测 2030 年" |
| **单因归果** | 复杂现象归给一个原因 | "并购潮还有利率、监管、估值等因素" |
| **权威借用** | 用"历史规律""必然"替代论证 | 要求给出可检验的推论 |
| **立场混入** | 分析里夹带价值判断 | 明确分离："这是分析" vs "这是立场" |

## 查不到怎么办

**不要编。** 三种处理方式：

1. **标注不确定**：`这个数字我没能独立核实，按原话记录。`
2. **降级表述**：把"这是错的"改成"我没有找到支持这个说法的证据"。
3. **跳过**：如果某个点查不到又不关键，不写它，别硬凑。

## 页脚怎么写

核查过的内容要在页脚列出，让用户能自己复核：

```
事实核对参考：Investopedia 康波词条、MoneyWeek 长波理论评述、
美国国债收益率历史数据（1981年10月峰值15.68%）。
```

**不要写**"经多方核实"这种空话——要么给具体来源，要么别说核实过。

## 政治与价值观内容

如果视频含政治表态、地域攻击、群体偏见：

1. **长文里**：可以标注出来（"这已经超出经济分析，是政治表态"），
   但不要删改原文——删了就失真，用户无法判断。
2. **解读里**：明确区分"技术分析"和"价值判断"两层，帮用户剥离。
3. **小红书文案里**：不引用、不评价、不放大，只谈知识框架。

这是三条不同的处理线，别混。
